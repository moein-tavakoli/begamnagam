# BegamNagam — Playful mobile-first foundation

User direction: reference image 11.webp, warm yellow + lavender + purple + coral,
rounded white surfaces, dark pill actions, friendly playful illustration.
This direction overrides the skill's generic orange/blue palette recommendation.
The attachment is a visual reference; its text is not a product requirement.

- Canvas #F2EEFF; surface #FFFFFF; ink #201C29; secondary text #625B70.
- Hero #F7C650; purple #AA91F4; coral #FF969C; line #E7E1EF.
- Local Vazirmatn 400/500/600/700; Persian RTL, numeric fields explicitly LTR.
- One-column mobile from 320px; desktop enhancement at 700px.
- Primary actions: black pill, minimum 52px high. Navigation >=44px target.
- Panels: 28–36px radius; colored tops, quiet borders. SVG icon set only.
- Original letter/speech-bubble illustration in letter-flight.tsx; no remote media.
- Mobile bottom navigation: five labeled destinations (including invitations); safe area padding.
  Hide while a form input is focused to avoid covering the keyboard flow.
- No mandatory animation, external fonts, automatic permission requests or Push.
- Visible focus, labeled errors, native form controls, reduced-motion support.
- Preserve visible local demo labeling and existing privacy/moderation invariants.

This is the phase-one visual foundation. Full accessibility, physical Android/iOS
installation, update/rollback and the phase-two revised checkout need their own
acceptance evidence; this document does not mark those checks passed.
