# گزارش کنترل بسته فاز صفر

شناسه: BN-DOC-QA-001 | تاریخ: ۲۴ اکتبر ۲۰۲۶

این کنترل‌ها فقط برای اسناد تحویلی هستند؛ هیچ تست برنامه، build، migration، اتصال یا سرویس تازه اجرا نشده است.

| کنترل | نتیجه |
| --- | --- |
| hash ۶۷ فایل source/config نسبت به snapshot آغاز فاز | PASS؛ تغییری در همین دامنه دیده نشد |
| hash فایل‌های بسته تاریخی پروپوزال۰٫۲ | PASS؛ نسخه پیشین حفظ شده |
| پوشش ماتریس | PASS؛ ۱۹ FR + ۱۷ NFR + ۶ MF + ۱۴ PW = ۵۶ نیازمندی و ۸ گروه آزمون سیاست |
| تصمیم‌های باز | PASS؛ هر ۱۱ شناسه D-01 تا D-11 پاسخ پیشنهادی/شرط توقف دارد |
| تفکیک مجوزها | PASS؛ فاز صفر مجاز، G0 در انتظار، Freeze انجام نشده و فاز یک/پیاده‌سازی غیرمجاز |
| پیوندهای محلی Markdown و نسخه یکپارچه | بررسی خودکار در بسته‌بندی؛ ارجاعات Markdown به بخش‌های همان HTML تبدیل می‌شوند |
| کنترل بصری HTML | اجرا نشد؛ ابزار مرورگر خطای در حال استفاده بودن پروفایل داد؛ هیچ پردازشی برای رفع آن متوقف یا تغییر داده نشد |
| مجوز فونت | فایل FONT-LICENSE.txt همراه بسته |
| تمامیت بسته | SHA-256 فایل‌ها در REVIEW-MANIFEST.json؛ CRC فایل ZIP کنترل می‌شود |

دامنه snapshot شامل کد/config انتخاب‌شده است؛ secret، دیتابیس، build و dependencyها در آن نیستند. از این کنترل، ثابت‌بودن تمام filesystem یا نتیجه امنیت/عملکرد برنامه استنتاج نمی‌شود.

وضعیت آزمون‌های اجرایی برنامه جدید: همه NOT TESTED. نتایج گزارش‌شده قبلی در PROTOTYPE-AUDIT مشخص شده‌اند. مشاهده HTML اسناد صرفاً کنترل خوانایی خروجی است و آزمون Mobile-first/PWA محصول محسوب نمی‌شود.
