# بگم نگم — تحویل فاز صفر

شناسه بسته: BN-G0-001 | نسخه خروجی: ۱٫۰ | تاریخ: ۲۴ اکتبر ۲۰۲۶

**وضعیت: READY FOR REVIEW — پذیرش G0 و Freeze در انتظار کارفرما؛ فاز یک مجوز ندارد.**

مجوز دریافت‌شده: «نسخه ۰٫۲ رو تأیید می‌کنم، فقط فاز صفر رو شروع کن و خروجی‌هاش رو برای بررسی بده. قبل از تأیید ما وارد فاز بعد و پیاده‌سازی نشو.»

نسخه ۰٫۲ ورودی مصوب این بررسی است. تاریخچه آن دست‌نخورده نگه داشته شده؛ عبارت‌های «مجوز صادر نشده» در فایل قدیمی، وضعیت هنگام انتشار همان نسخه‌اند. ثبت مجوز جدید در AUTHORIZATION.json است. تأیید نسخه ۰٫۲ جای تأیید تصمیم‌های تازه این بسته یا مجوز اجرای بعدی را نمی‌گیرد.

## نتیجه قابل تصمیم

پیشنهاد فنی، حفظ Next.js و Django، معماری یکپارچه، PostgreSQL به‌عنوان مرجع و Redis/RabbitMQ برای کارهای موقت و صف است. برای شروع، متن‌های مصوب با انتخاب محدود مدل پیشنهاد می‌شوند؛ بازنویسی آزاد AI به تصمیم و ارزیابی جدا وابسته است. WebSocket برای این دامنه لازم نیست.

Mobile-first و PWA کامل در دامنه نسخه اول می‌مانند. نمونه موجود فقط manifest ساده دارد؛ شواهدی از Service Worker و مسیر کامل نصب/آفلاین/به‌روزرسانی در کد بررسی‌شده دیده نشد. بنابراین PWA پذیرفته‌شده محسوب نمی‌شود.

کاوه‌نگار و زرین‌پال برای بررسی فنی بعدی پیشنهاد می‌شوند، با شرط مجوز محتوای سرویس، تعرفه قطعی، حداقل پرداخت، رفع نتیجه مبهم و بازپرداخت. انتخاب تجاری نهایی انجام نشده است. عدد ۲۰۰۰ تومان همچنان فقط قیمت نمونه است. سرویس پیامکی مجاز برای OTP لزوماً مجاز برای پیام بازخورد ناشناس نیست.

## مرز کار انجام‌شده

این تحویل حاصل مطالعه اسناد، بررسی خواندنی کد و تحقیق منابع عمومی است. وایرفریم و API پیشنهادی در حد سند هستند. کد برنامه، تنظیمات اجرا و دیتابیس تغییر نکردند؛ سرویس نصب یا راه‌اندازی نشد؛ تست برنامه، ارسال SMS، پرداخت، خرید، تماس با ارائه‌دهندگان یا استقرار انجام نشد. فقط اسناد و ابزار بسته‌بندی مستندات تهیه شدند.

نتایج آزمون‌های قدیمی با برچسب «گزارش قبلی» آمده‌اند؛ آزمون‌های برنامه جدید همگی اجرا نشده‌اند. کنترل صحت بسته و hash فایل‌ها، آزمون برنامه محسوب نمی‌شود.

## اقدام موردنیاز برای ادامه

کارفرما می‌تواند این بسته و تصمیم‌های D-01 تا D-11 را تأیید یا اصلاح کند. پذیرش G0، Freeze همین نسخه و اجازه شروع فاز یک سه فیلد مستقل‌اند. تا ثبت مجوز صریح فاز یک، کار در همین نقطه متوقف می‌ماند. انتخاب سرویس، هزینه‌کرد، پایلوت و انتشار نیز مجوزهای مستقل دارند.
