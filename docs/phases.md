# برنامه جاری توسعه مرحله‌ای

مبنای شماره‌گذاری، [بسته فاز صفر نسخه۱٫۰](phase-zero-v1/README.md) و [برنامه پروپوزال۰٫۲](proposal-v0.2/PHASE-PLAN.fa.md) است. برنامه قدیمیِ نمونه، شماره‌های متفاوتی داشت و مبنای اجرای جاری نیست. مجوز قبلی فازهای۰تا۲ در بسته فاز دو و مجوز جدید ادامه تا فاز۶ با تعویق تست‌های انسانی در [AUTHORIZATION.json](release-v0.4/AUTHORIZATION.json) ثبت است. commit محلی مجاز است؛ push و انتشار بیرونی انجام نمی‌شوند.

## فاز صفر — تثبیت محصول و امکان‌سنجی

PRD، دامنه هفت موضوع مثبت و رفتاری، ADR انتخاب Django/Next.js، قرارداد API و داده، وایرفریم Mobile-first، اقتصاد هر پیام، ماتریس ۵۶ نیازمندی و Freeze Master نامزد در بسته فاز صفر تحویل شده‌اند. دستور جاری اجازه پیشروی محلی را می‌دهد؛ انتخاب تجاری ارائه‌دهنده، قیمت فروش، هزینه‌کرد و امضای Freeze رسمی از آن استنتاج نمی‌شود. تصمیم‌های لازم برای demo با پیش‌فرض مستند بسته شده‌اند و تصمیم‌های واقعی به فاز مربوط واگذار شده‌اند.

## فاز یک — بنیاد توسعه

محیط Docker Compose شامل PostgreSQL17، Redis7.4، RabbitMQ4.4، worker/beat، Django و Next.js؛ migration افزایشی، نشست/CSRF، نقش‌های مدیر، API پایه، آداپتورهای demo/disabled، healthcheck، قفل وابستگی‌ها و CI فراهم‌اند. مدل‌های پرداخت، رویداد مالی، ارسال، refund و outbox مستقل‌اند.

شواهد G1: ساخت کامل imageها، راه‌اندازی محیط جدا با دیتابیس تازه، migration/readiness و آزمون PostgreSQL موفق‌اند. ناسازگاری صف موقت Celery با RabbitMQ4.4 اصلاح شد. جزئیات و تکرار آزمون در [گزارش زیرساخت](phase-two/INFRASTRUCTURE.md) است. گزارش قدیمی فاز یک مانع شبکه را ثبت کرده بود؛ این گزارش جایگزین وضعیت آن مانع است.

## فاز دو — محصول کامل آزمایشی

رابط فارسی RTL با جهت بصری مصوب، هفت موضوع، ورود OTP آشکارا آزمایشی، گیرنده ثابت در quote، متن کامل شامل برند و مسیر توقف دریافت، مبلغ صحیح تومان، سفارش idempotent، پرداخت demo، صف قابل بازیابی، رسید، سابقه پوشیده و ترجیح دریافت پایه پیاده‌سازی شده‌اند. محدودیت فرستنده، گیرنده و جفت از دیتابیس دفاع می‌شود. قالب‌های بررسی‌شده تنها متن مجاز ارسال آزمایشی‌اند؛ polling محدود استفاده می‌شود و ارتباط مستقیم بین طرفین وجود ندارد.

PWA شامل manifest و آیکون‌های واقعی، SW با کش عمومی محدود، fallback آفلاین ناشناس، راهنمای نصب متناسب پلتفرم و update صریح در نقطه امن است. API و اطلاعات خصوصی کش یا replay نمی‌شوند.

**وضعیت G2:** پیاده‌سازی نرم‌افزار و آزمون‌های محلی/کانتینر/مرورگر انجام شده‌اند؛ پذیرش کامل G2 هنوز باز است، چون نصب و اجرای مستقل روی دستگاه فیزیکی Android/iOS آزموده نشده است. عرض موبایل در مرورگر رومیزی جای آن شاهد نیست. جدول شواهد و موارد آزموده‌نشده در [گزارش فاز دو](phase-two/README.fa.md) آمده است. هیچ OTP/SMS واقعی یا جابه‌جایی پول رخ نمی‌دهد.

## فاز سه — اتصال ارائه‌دهندگان

انتخاب و قرارداد OTP/SMS/پرداخت، مجوز و سقف هزینه، آداپتورهای واقعی، تأیید سمت سرور، callback معتبر، نتیجه مبهم، تطبیق و refund عملیاتی. کلاینت‌ها، ثبت intent/lease، verify مستقل، استعلام نامعلوم، بودجه و قراردادهای HTTP محلی در نسخه۰٫۴ پیاده و آزموده شده‌اند. پذیرش خارجی G3 به کلید/قرارداد/تست sandbox واقعی و روش refund پس از تسویه وابسته است و PASS ادعا نمی‌شود. [گزارش اتصال‌ها](release-v0.4/README.fa.md).

## فاز چهار — ایمنی و عملیات

مسیر stop/report بدون حساب و با توکن امن، نقش/ممیزی کامل، نگهداری و حذف داده، backup/restore و سخت‌سازی امنیت و چرخه PWA. کنترل‌های نرم‌افزاری در نسخه۰٫۵ پیاده شده‌اند؛ تست‌های خودکار، چرخش کلید و restore جدا انجام شده‌اند. انتساب مسئولان واقعی و بازبینی انسانی همچنان نگه داشته شده است. [گزارش ایمنی](release-v0.5/README.fa.md).

## فاز پنج — پایلوت داوطلبان و دستگاه واقعی

بخش محلی در نسخه۰٫۶ با۱۲سناریوی مصنوعی روی مسیرهای برنامه و HTTP fixture اجرا شد: هفت موضوع، verify مستقل، callback تکراری، stop/refund، گزارش و halt. [نتیجه](release-v0.6/README.fa.md). پایلوت بزرگسالان داوطلب، بودجه واقعی، بازخورد، نصب و ماتریس کامل وب/standalone طبق دستور کارفرما نگه داشته شده است؛ G5 هنوز پذیرفته نیست. آزمون مصنوعی معادل پایلوت داوطلبان نیست.

## فاز شش — آمادگی انتشار

نسخه۰٫۷ بار مصنوعی با۱۰۰۰حساب/۱۰نشست فعال،۲۴۰۰درخواست موفق و۳۰جریان کامل پیام، بازیابی رمز‌شده با حفظ stop پس از snapshot، تمرین بازگردانی image پس از شکست candidate، بررسی چندتب PWA و تنظیمات خصوصی HTTPS را ثبت می‌کند. [بسته نهایی](release-v0.7/README.fa.md) و [دروازه انتشار](release-v0.7/READINESS.json) شواهد و موانع را جدا نشان می‌دهند. ظرفیت vendor، گوشی واقعی، rollout عمومی/asset چندنسخه‌ای و پذیرش انسانی هنوز بازند؛ G6 رسمی PASS نیست. هدف۱۰۰۰ حساب کم‌فعال معادل۱۰۰۰ درخواست هم‌زمان نیست. هیچ push یا انتشار عمومی انجام نشده است.
