# کلیدهای خصوصی و دیباگ

دیباگ بک‌اند به‌صورت پیش‌فرض خاموش است. Compose، پروفایل واقعی لوکال و پروفایل‌های انتشار نیز `DEBUG=0` دارند. در فرانت، نشانگر توسعهٔ Next خاموش و source map مرورگر در build انتشار غیرفعال است؛ ویرایش لوکال همچنان از `next dev` و Fast Refresh استفاده می‌کند.

سه کلید برنامه باید صریحاً در محیط پردازش تنظیم شوند؛ مقدار ثابت یا کلید رمزنگاری مشتق‌شدهٔ خودکار در کد وجود ندارد:

| متغیر | کاربرد |
| --- | --- |
| `DJANGO_SECRET_KEY` | امضای نشست و توکن‌های جنگو |
| `PHONE_HASH_KEY` | تطبیق شماره با HMAC کلیددار |
| `PHONE_ENCRYPTION_KEY` | رمزگذاری شماره‌ها و متن‌های خصوصی |
| `PHONE_ENCRYPTION_FALLBACK_KEYS` | کلیدهای قبلی رمزگذاری؛ فقط هنگام چرخش برنامه‌ریزی‌شده |
| `POSTGRES_PASSWORD` / `RABBITMQ_PASSWORD` | رمز سرویس‌های داده؛ Compose مقدار جایگزین ثابت ندارد |
| `KAVENEGAR_API_KEY` | اعتبارنامهٔ پیامک؛ فقط بک‌اند و worker |
| `GAPGPT_API_KEY` | اعتبارنامهٔ بازنویسی؛ خالی تا تنظیم مستقل |
| `ZARINPAL_MERCHANT_ID` | تنظیم درگاه؛ پرداخت فعلاً بسته است |

مقادیر فعلی فقط در env خصوصی نگهداری می‌شوند. `.env.example` جای‌نگهدار خالی/نمونه دارد؛ مقدار واقعی در Git قرار نمی‌گیرد. `scripts/init-local.py` برای نصب تازه env با کلیدهای مستقل و مجوز0600 می‌سازد و فایل موجود را جایگزین نمی‌کند. Compose فایل `.env` و اجرای واقعی لوکال `scripts/dev-product.py` فایل خصوصی را به متغیرهای محیطی پردازش تبدیل می‌کنند؛ Django فایل env را خودکار نمی‌خواند. فرانت تنها تنظیمات عمومی `APP_BASE_URL` و `SEO_INDEXABLE` را می‌گیرد.

نبود کلید اصلی یا نمونهٔ جای‌نگهدار، startup را متوقف می‌کند؛ نبود کلید اختیاری سرویس، همان قابلیت را بسته نگه می‌دارد. نسخهٔ واقعی، دیباگ روشن و کلیدهای ضعیف/وابسته را نمی‌پذیرد. کلیدهای موجود در این تغییر عوض نشده‌اند؛ چرخش HMAC یا کلید رمزنگاری باید با طرح حفظ تطبیق حساب‌ها و داده‌های قبلی انجام شود.

آزمون‌های خودکارِ جدا و مرحلهٔ `collectstatic` داخل ساخت image از کلیدهای تصادفی کوتاه‌عمر در env همان فرایند استفاده می‌کنند. این مقادیر محصول نیستند، به فایل نوشته نمی‌شوند و به `ARG`/`ENV` لایهٔ image راه نمی‌یابند. برنامه در startup عادی هیچ کلیدی تولید نمی‌کند. تست فنی هم SMS یا پرداخت واقعی را فعال نمی‌کند.

تغییرات فعلاً در کد و اجرای لوکال‌اند؛ استقرار روی سرور دستور مستقل لازم دارد. Context7 در این نشست موجود نبود؛ [راهنمای رسمی استقرار Django](https://docs.djangoproject.com/en/5.2/howto/deployment/checklist/) و مستندات نسخهٔ نصب‌شدهٔ Next برای `devIndicators` و `productionBrowserSourceMaps` بررسی شدند.
