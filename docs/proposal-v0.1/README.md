# بسته تصمیم‌گیری بگم نگم

نسخه: ۰٫۱ | تاریخ: ۲۴ اکتبر ۲۰۲۶ | وضعیت: پیش‌نویس برای بررسی و تأیید

این بسته مجوز اجرا نیست. تهیه این اسناد تنها کار مجاز این مرحله است. شروع فاز صفر، تغییر کد، راه‌اندازی سرویس تازه، اتصال ارائه‌دهندگان، هزینه‌کرد و استقرار به تأیید صریح کارفرما نیاز دارند.

## ترتیب مطالعه

۱. [پروپوزال پیاده‌سازی](PROPOSAL.fa.md): مسئله، محصول پیشنهادی، دامنه، معماری، هزینه و ریسک.

۲. [Freeze Master](FREEZE-MASTER.fa.md): مبنای پیشنهادی نیازمندی‌ها، موارد باز، روش تصویب و کنترل تغییرات.

۳. [فازبندی اجرایی](PHASE-PLAN.fa.md): شروع از فاز صفر، خروجی‌ها، وابستگی‌ها، معیار پذیرش و مجوز هر فاز.

فایل `REVIEW-MANIFEST.json` شناسه، وضعیت تصویب و اثر انگشت SHA-256 اسناد همین بسته را ثبت می‌کند. اثر انگشت، صحت محتوا یا تصویب کارفرما را اثبات نمی‌کند؛ فقط نسخه بررسی‌شده را مشخص می‌کند.

## درخواست تصمیم

در این مرحله تنها تصمیم اجرایی قابل درخواست، تأیید شروع **فاز صفر** است. نمونه عبارت تصمیم: «نسخه ۰٫۱ بسته پیشنهاد را برای شروع فاز صفر تأیید می‌کنیم.» این عبارت تا زمانی که کارفرما واقعاً آن را اعلام نکرده، هیچ مجوزی ایجاد نمی‌کند.

تصویب این بسته برای فاز صفر به معنی تصویب قیمت نهایی، ارائه‌دهندگان، Freeze نهایی نیازمندی‌ها یا اجرای فاز یک نیست. فاز صفر باید این تصمیم‌ها را روشن کند و خروجی آن دوباره تأیید شود.

نمونه قبلی موجود در مخزن، صرفاً ورودی ارزیابی فاز صفر است. از وجود نمونه، انجام‌شدن فازهای این برنامه نتیجه گرفته نمی‌شود؛ حذف، بازنویسی یا استفاده مجدد از آن نیز در این مرحله انجام نمی‌شود.
