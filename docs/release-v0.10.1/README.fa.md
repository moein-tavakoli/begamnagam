# نسخه۰٫۱۰٫۱ — برداشتن سقف هزینهٔ روزانهٔ ارسال واقعی

بررسی مستقیم روی سرور نشان داد سه سفارش آخر با `policy_unavailable`، صفر تلاش شبکه و بازگشت سهمیه لغو شده‌اند. سقف رزرو روزانه۱۰۰٬۰۰۰ریال پر بود؛ درخواست به کاوه‌نگار نرسیده بود. کارفرما پس از توضیح علت، صریحاً خواست سایت این سقف را نداشته باشد.

متغیر خصوصی `PROVIDER_DAILY_BUDGET_UNLIMITED=1` فقط در پروفایل هدیهٔ واقعیِ دارای پرداخت بسته، سقف هزینهٔ روزانهٔ مشترک OTP، پیام و دعوت را برمی‌دارد. دفتر هزینه، ردیف‌های روزهای قبلی و رزرو هر عملیات برای حسابرسی حفظ می‌شوند؛ صفرکردن یا بزرگ‌کردن مصنوعی سقف انجام نمی‌شود. مقدار پیش‌فرض flag صفر است و تنظیم نامعتبر در startup رد می‌شود.

سه هدیهٔ اولیه و پاداش دعوت، تعدیل محتوا، قطع دریافت، قواعد مقابله با سوءاستفاده، ساعت ارسال، پرداخت بسته و کنترل هزینهٔ غیرمنتظرهٔ هر تماس حفظ می‌شوند. سفارش لغوشدهٔ قبلی بازپخش نمی‌شود؛ سهمیهٔ آن قبلاً برگشته است. هیچ پیامک واقعی برای بررسی این انتشار فرستاده نمی‌شود.

علت معتبر داخلیِ توقف پیش از provider اکنون دقیقاً در outbox/delivery ثبت می‌شود؛ متن آزاد exception ذخیره نمی‌شود و رسید عمومی همچنان جزئیات اعتبار و خطاهای فنی را پنهان می‌کند. snapshot عملیات نامحدودبودن را صریح نشان می‌دهد و هشدار سقف روزانه در این حالت غیرفعال است.

اصلاح۰٫۱۰٫۱ روی سرور فعال است؛ backend/worker/beat به‌روز و frontend۰٫۱۰٫۰، proxy و هر۳سرویس داده بدون recreate حفظ شده‌اند. migration ندارد؛ dump رمز‌شده پیش از تغییر ذخیره شد. ۲۶۳آزمون کامل PostgreSQL/Redis، پذیرش پروفایل واقعی با transport ساختگی و دفتر واقعیِ پایگاه تست در حالت بودجهٔ پر، و۳۵بررسی HTTPS موفق‌اند. هر۸سرویس سالم‌اند؛ ماندهٔ هدیه و دفتر هزینهٔ روزانه تغییر نکرده‌اند. مسیر عادی اینترنتی این نشست بررسی نشده و آزمون دامنه از IP لبه با TLS معتبر بوده است.

در backend، worker و beat، flag نامحدود فعال است؛ snapshot عملیات limit=null می‌دهد و ارسال باز است. دفتر همان۱۰۰٬۰۰۰ریال قبلی را حفظ کرده و آن عدد دیگر سقف ارسال نیست. ساعت ارسال فعلی۹تا۲۱به وقت تهران است؛ بیرون بازه، پیام در صف می‌ماند. API و مدل GapGPT همچنان خالی‌اند و هیچ پیامک واقعی/تماس پولی AI برای این انتشار انجام نشده است. [شواهد استقرار](../deployments/ct115-0.10.1.json) وضعیت و checksumها را ثبت می‌کند.
