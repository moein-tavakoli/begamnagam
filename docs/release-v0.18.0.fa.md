# انتشار۰٫۱۸٫۰ — API و مستندات خصوصی

کارفرما استقرار API و تحویل لینک Swagger خصوصی به فرانت‌کار را صریحاً
درخواست کرده است. این بسته API نسخهٔ دوم با۴۴عملیات و ورود مخصوص مشاهدهٔ
مستندات را منتشر می‌کند. حساب تحویلی فقط مجوز `core.view_api_documentation`
دارد؛ staff، superuser و Account محصولی ندارد. فایل‌های schema، راهنما و
assetها نیز پشت همین مجوزند. نشست ورود۸ساعته، محدودیت تلاش و CSRF برقرارند.

مهاجرت۰۰۳۶ فقط مجوز جدید را تعریف می‌کند. قبل از اعمال آن، بکاپ رمز‌شده،
بازیابی مستقل، اجرای تست روی تصویر نهایی و بررسی حفظ فیلدهای موجود لازم‌اند.
مقادیر اعتبار، شماره‌های تأییدشده، تنظیمات واقعی OTP/SMS، کلیدها و سیاست
پرداخت حفظ می‌شوند؛ استقرار، پیامک آزمایشی یا پرداخت و AI واقعی ایجاد نمی‌کند.
شش فرانت با حفظ دارایی‌های نسخهٔ قبلی و ظرفیت جاری به‌روز می‌شوند.

انتشار از `dev` به `prod` با PR و پس از موفقیت بررسی‌های backend، frontend
و compose انجام می‌شود. گزارش نهایی شامل commitها، CI، digest تصاویر،
بکاپ/بازیابی و نتیجهٔ دسترسی مجاز/غیرمجاز HTTPS در
[شواهد انتشار](https://github.com/moein-tavakoli/begamnagam/releases/tag/v0.18.0)
ثبت می‌شود. وجود این سند به‌تنهایی پایان استقرار را تأیید نمی‌کند.

پس از تحویل، `API_DOCUMENTATION_ENABLED=0` همهٔ مستندات HTTP و ورودشان را
می‌بندد و API محصول باقی می‌ماند. اطلاعات ورود فرانت‌کار فقط در فایل خصوصی
تحویل داده می‌شود و در Git، URL یا شواهد عمومی انتشار قرار نمی‌گیرد.

Context7 در این نشست در دسترس نبود؛ روال انتشار قبلی و راهنماهای رسمی
[Django](https://docs.djangoproject.com/en/5.2/ref/django-admin/)،
[Compose](https://docs.docker.com/reference/cli/docker/compose/up/) و
[GitHub](https://docs.github.com/en/rest/pulls/pulls) مرجع عملیات‌اند.
