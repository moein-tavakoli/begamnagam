# گزارش اعتبارسنجی جاری — نسخه۰٫۳٫۱

تاریخ:۲۴ اکتبر۲۰۲۶. این سند وضعیت جاری را جایگزین گزارش نمونه قدیمی می‌کند؛ سوابق اصلی در Git و بسته‌های hashشده فاز صفر/یک حفظ شده‌اند. [گزارش فاز دو](phase-two/README.fa.md) شواهد محصول و [گزارش زیرساخت](phase-two/INFRASTRUCTURE.md) محیط، روش اجرا و محدودیت‌ها را شرح می‌دهند.

## نتایج

- بک‌اند native:۴۶ تست روی PostgreSQL17 و Redis15، بدون skip. شامل آزمون هم‌زمانی واقعی قفل‌ها، مالکیت/CSRF/OTP، quote، سفارش و پرداخت تکراری، مدل مالی مستقل، refund آزمایشی، سقف گیرنده و جفت و۱۲۰ ورودی مصنوعی کنترل محتوا.
- فرانت:۱۰ تست، TypeScript و build تولیدی native و Docker موفق. مسیرهای RTL، شماره‌های فارسی/عربی، هدر CSRF، retry و مرزهای کش خصوصی آزموده شدند.
- محیط پاک Compose با دیتابیس تازه و RabbitMQ4.4، migration/readiness و مسیر کامل demo موفق. قفل کامل وابستگی‌های Linux و cryptography46.0.7 در image استفاده شدند؛ نتایج قبلی با نسخه44 یا Rabbit4.2 جای این آزمون را نمی‌گیرند.
- قطع واقعی RabbitMQ، worker و beat: ثبت پرداخت و outbox با صف خاموش حفظ شد؛ پس از راه‌اندازی، همان سفارش پردازش و تکرار پرداخت به همان شناسه رسید. در همه سفارش‌های پرداخت‌شده محیط جدا، یک capture و یک attempt تحویل ثبت شده بود.
- مرورگر رومیزی با عرض موبایل: ورود، پیش‌نمایش کامل، خرید demo، رسید مالی/ارسال جدا، سابقه، خروج و Back؛ update در سفارش باز رد و بعد پاک‌کردن فرم با اقدام صریح فعال شد. کش فقط چهار فایل عمومی داشت؛ خطای اجرایی JavaScript مشاهده نشد.
- بررسی foundation: هدر no-store، manifest، ابعاد واقعی آیکون‌ها، SW و fallback آفلاین موفق. schema/migration سازگار است. manifest بسته‌های تاریخی بدون تغییر مانده است.

آزمون دود شماره‌های مصنوعی در دیتابیس محلی می‌سازد. هیچ پیامک، OTP، مدل ابری یا پرداخت واقعی فراخوانی نشده است. Context7 به سقف سهمیه رسیده بود؛ مستندات رسمی و آزمون اجرا مبنا شدند. GitHub CI اجرا نشده، چون هیچ push انجام نشده است.

## پذیرش باز

پیاده‌سازی محلی فازهای۰تا۲ آماده بررسی است. پذیرش کامل G2 هنوز باز است: نصب Android/iOS فیزیکی، پوشش کامل مرورگر/standalone، ارزیابی کامل WCAG2.2AA و سناریوهای update چند تب/rollback روی دستگاه واقعی آزموده نشده‌اند. نتایج مرورگر رومیزی، manifest یا تست خودکار جای این شواهد نیستند. بودجه عملکرد روی گوشی و داده میدانی Core Web Vitals اندازه‌گیری نشده‌اند.

کیفیت انتخاب مدل واقعی Ollama، providerهای OTP/SMS/پرداخت، بار هدف، backup/restore عملیاتی، پایلوت و عرضه عمومی در فازهای بعد بررسی می‌شوند. کار جاری وارد فازسه نشده است.
