# گزارش اعتبارسنجی جاری — رابط۰٫۸ بر پایهٔ۰٫۷

تاریخ۲۴اکتبر۲۰۲۶. اصلاح رابط۰٫۸ شامل معرفی و فرم تمام‌صفحه، حذف موارد مشخص‌شده در نظرهای مرورگر و درج مستقیم مثال است. ۱۳ تست فرانت و typecheck موفق‌اند؛ مرورگر شش اندازهٔ موبایل، هر هفت موضوع، حفظ متن و مسیر کامل پرداخت demo تا رسید را بررسی کرد. [شواهد۰٫۸](release-v0.8/README.fa.md). بک‌اند این به‌روزرسانی همان کد اعتبارسنجی‌شدهٔ۰٫۷ است. build تولیدی/PWA و image جدید در چرخه ویرایش این رابط اجرا نشدند.

سوابق زیر مربوط به بستهٔ۰٫۷ هستند.  مرجع کامل [بسته نهایی](release-v0.7/README.fa.md)، [شواهد ماشین‌خوان](release-v0.7/EVIDENCE.json) و [پوشش۵۶نیازمندی](release-v0.7/TRACEABILITY.fa.md) است. بسته‌های فاز صفر/یک/دو و نسخه‌های۰٫۴تا۰٫۶، سوابق تاریخی‌اند؛ hash و متن پذیرش آن‌ها بازنویسی نشده‌اند.

- ۸۶ تست backend روی PostgreSQL17/Redis بدون skip؛ اجرای native و محیط تازه Docker. کنترل‌های provider روی HTTP loopback، هم‌زمانی، CSRF، OTP، منع دریافت، refund، مجوز، retention و privacy پوشش دارند.
- ۱۳ تست frontend، TypeScript، build تولیدی native/Docker و lint workflow موفق؛ GitHub CI اجرا نشده چون push انجام نشده است.
- Compose تازه با RabbitMQ4.4.0، readiness، smoke و foundation موفق. شروع اولیه broker روی میزبان شلوغ یک health failure گذرا داشت؛ پس از healthy شدن همان container، up تکرار و موفق شد. نسخه broker در benchmark نیتیو۴٫۲٫۹ بود؛ این دو شاهد یکی نیستند.
- ۱۲ سناریوی پایلوت مصنوعی، هشت capture و یک refund، هفت submission محتوای fixture؛ هیچ داوطلب یا provider خارجی/پول واقعی در این اعداد نیست.
- آزمون بار:۱۰۰۰حساب مصنوعی/۱۰نشست،۲RPS برای۹۰۰ثانیه و۱۰RPS برای۶۰ثانیه،۲۴۰۰موفق/صفر خطای غیرمنتظره. p95 عادی۱۴۵٫۵۷۶ و جهشی۲۱۲٫۳۸۵میلی‌ثانیه؛۳۰جریان کامل demo با p95 حدود۴۰۰میلی‌ثانیه. کد runtime طی اندازه‌گیری ثابت بود. بار خواندنی معادل نرخ ارسال پیام یا ظرفیت۱۰۰۰کاربر هم‌زمان نیست.
- Chromium رومیزی production: دو تب کنترل‌شده، ممانعت update با فرم باز، حفظ draft، نصب صریح بدون reload تب دیگر، بازگشت worker اصلی، چهار فایل عمومی cache و fallback ناشناس با توقف واقعی سرور. JS اولیه فشرده۱۵۷۴۰۱بایت و کل انتقال حدود۳۰۵KB بود؛ اندازه‌گیری گوشی/field CWV انجام نشده است.
- restore دیتابیس جدید schema0008: صفر اختلاف مالی/منع دریافت،۶۶فیلد رمز معتبر، حفظ stop مصنوعی ثبت‌شده پس از snapshot و dispatch متوقف. حذف حساب پس از snapshot مستقیماً در این تمرین اجرا نشد؛ بازیابی خارج دستگاه/قطع منبع باز است.
- candidate فرانت با exit23 عمداً خراب و سپس همان image سالم برگردانده شد؛ health و صفحه برگشت و watermark مالی ثابت ماند. rollback چندنسخه‌ای asset، TLS عمومی و rollout بیرونی آزموده نشده‌اند.
- `check --deploy --fail-level WARNING` با settings انتشار و provider خاموش بدون اخطار موفق؛ topology مستقل Compose و Caddy validate موفق. domain، digestهای مصوب، گواهی واقعی و تنظیم پشتیبانی در اختیار نیستند؛ config lint به معنی deploy نیست.

تمام تست‌های انسانی مطابق دستور نگه داشته شده‌اند: [چک‌لیست](release-v0.7/HUMAN-REVIEW.fa.md). `release_readiness` وضعیت `live_ready:false` را درست گزارش می‌کند؛ پذیرش کامل G2/G3/G5/G6 و Freeze رسمی باز است. Context7 در ابزارهای این نوبت موجود نبود؛ مستندات رسمی و کد نصب‌شده و نتیجه اجرای محلی مبنا شدند. هیچ push، انتشار عمومی، مدل ابری، OTP/SMS واقعی یا انتقال وجه انجام نشده است.
